# 只查语法，不替你完成任务

本课假定你会读取数组形状、取列和做基本计算。若不熟悉，先练习以下写法。

```python
import numpy as np
A = np.array([[1.,2.,3.],[4.,5.,6.]])
print(A.shape)       # 行数、列数
print(A[0])          # 第一行
print(A[:,2])        # 第三列
print(A.T.shape)     # 转置后行列互换
print(A * 2)         # 逐元素运算
print(A ** 2)        # 逐元素平方
print(np.sum(A, axis=0))  # 沿行方向汇总，留下每列
print(np.sum(A, axis=1))  # 沿列方向汇总，留下每行
```

矩阵乘法使用`@`，与逐元素乘法`*`不同。广播允许一条长度3的向量作用于每一行，但要先确认含义与形状。
本课的旋转矩阵是已提供输入，不要求你推导或估计旋转矩阵；你需要正确使用它，并解释变换方向。
