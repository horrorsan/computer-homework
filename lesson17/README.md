## 补按顺序走深的 DFS 8分钟

删除 `dfs_path` 开头的 `raise NotImplementedError`，再用代码替换各局部 TODO 的占位行。每个栈框保存当前位置和下一个尚未查看的邻居。走到尽头时，给出的框架会退回还有分支的位置。

```text
新邻居已经在 parent 里时，跳过这一轮。
否则登记 parent[neighbor] = ____。
若 neighbor 是目标，返回 reconstruct_path(____, ____)。

```

保留已有的 `emit`，它会自动记下发现、检查和回退。保存 `practice.py`，运行 `python self_check.py`。先核对 DFS 的来路、回退和邻居顺序，BFS 各项暂时为⏳。

| 看到什么 | 先检查哪里 |
| --- | --- |
