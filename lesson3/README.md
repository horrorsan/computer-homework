# 第 3 次课发放

更新：2026-09-16 PDT

发给学生的是本目录下的 `学生作业包/`。

## 你怎么打出 zip

在 GitHub Desktop 打开本仓 → Show in Finder / Explorer → 进入 `handouts/第3课/`

**Mac / 课堂 Linux**

```bash
cd handouts/第3课
sh pack.sh
```

会生成 `HeroDungeon-第3课-学生作业包.zip`，把这个文件发群。

**Windows**

右键 `学生作业包` 文件夹 → 压缩 → 发群。

## 包内顺序（学生解压后）

1. 读 `00-请先读我.txt`
2. 读 `docs/lesson-03.md`
3. 只改 `src/herodungeon/m1_inventory/inventory.py`
